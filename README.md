# teecher-ios

This is the source code for the iOS app of [teech.ai](https://devpost.com/software/teech-ai), a Cal Hacks project.

## Running the code

To build and run the project, you'll need a Mac with Xcode 26.x or above installed, as well as a **physical device** running iOS 26.x or above.

Clone the repository and open the `.xcodeproj` file. Select your development team under "Signing and Capabilities" in the project settings.

[Enable development mode](https://developer.apple.com/documentation/xcode/enabling-developer-mode-on-a-device) on your iPhone, if it is not enabled already.

Connect your iPhone and select from the device menu (located on the top); then, run `Cmd` + `R` to install and run the app.
